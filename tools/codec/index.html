Base64 与 URL 编码转换

Base64 编码解码完整支持中文，内部先把文本转成 UTF-8 字节再编码。URL 编码使用 encodeURIComponent 规则。

怎么用

在左边输入内容，选一个转换方向。「结果放回输入」用来做连续转换，比如一段既做了 URL 编码又做了 Base64 编码的字符串，可以先解一层再解一层。

常见问题

为什么中文的 Base64 结果和别的工具不一样？

Base64 编码的是字节而不是字符，所以结果取决于先用哪种字符编码把文本转成字节。本工具统一使用 UTF-8，这是 Web 上的通行做法。如果对方工具用的是 GBK，结果自然不同。

URL 编码用的是哪个函数？

encodeURIComponent。它会把 & = ? / # 这类分隔符一并编码，适合用来编码单个查询参数的值。如果你要编码的是一整个 URL，用它会把 :// 也编码掉，那种场景应该用 encodeURI。

Base64 解码失败是什么原因？

通常是两种情况：字符串被截断了，或者缺少末尾用来补位的等号。Base64 的长度必须是 4 的倍数，不足时用 = 补齐。另外如果原始字节不是合法的 UTF-8 序列，解码成文本时也会失败。

Base64 是加密吗？

不是。Base64 只是把二进制数据表示成纯文本字符的编码方式，任何人都能直接解开。不要用它来保护密码或任何敏感信息。
