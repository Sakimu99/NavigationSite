工具

在线开发工具

几个平时自己会反复用到的小工具。全部在你的浏览器里本地运行，输入的内容不会上传到任何服务器。

JSON 格式化 编码转换 正则测试 时间戳转换

JSON 格式化与校验

把压缩成一行的 JSON 展开成带缩进的可读格式，或者反过来压缩回一行。语法有问题时会直接告诉你错在哪里。

缩进固定为 2 个空格。格式化会顺带完成一次语法校验，解析失败时会给出 JavaScript 引擎返回的具体错误位置。

Base64 与 URL 编码转换

Base64 编码解码支持中文（内部先转成 UTF-8 字节再编码），URL 编码使用 encodeURIComponent 规则。

「结果放回输入」用来做连续转换，比如先 URL 解码再 Base64 解码。解码失败通常意味着输入里混进了非法字符或缺少补位的等号。

正则表达式测试

输入正则和测试文本，列出每一处匹配的位置、匹配内容，以及编号分组和具名分组的值。

不加 g 标志时只返回第一处匹配。为了避免病态正则把页面卡死，全局匹配最多列出 2000 条结果。

Unix 时间戳转换

时间戳转成可读时间，或者把某个日期时间转回时间戳。秒级和毫秒级都支持，按位数自动判断。

10 位及以内按秒级解析，超过则按毫秒级解析。「本地时间」使用你当前设备的时区，ISO 8601 与 UTC 结果则始终是零时区。
