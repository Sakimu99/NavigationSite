JSON 格式化与校验

把压缩成一行的 JSON 展开成带缩进的可读格式，或者反过来压缩回单行。语法有问题时会直接指出错在第几个字符。

怎么用

把 JSON 粘贴到左边，点「格式化」得到缩进两个空格的可读版本，点「压缩为单行」则去掉所有空白。两个操作都会先完整解析一遍，所以也等于做了一次语法校验。

常见问题

数据会上传到服务器吗？

不会。整个过程用浏览器内建的 JSON.parse 和 JSON.stringify 完成，输入的内容不会离开你的设备。

为什么提示 Unexpected token？

最常见的三个原因：字符串用了单引号、键名没加引号、数组或对象末尾多了一个逗号。JSON 规范只接受双引号，并且不允许尾随逗号，这三点都和 JavaScript 对象字面量不一样。

缩进能改成 4 个空格或 Tab 吗？

目前固定为 2 个空格。这是 JSON 配置文件和大多数前端项目的通行约定，暂时没有做成可选项。

能处理多大的 JSON？

受浏览器内存限制，几 MB 的文件通常没问题。如果是几十 MB 以上的日志或导出数据，建议改用命令行的 jq，浏览器一次性解析会明显卡顿。
